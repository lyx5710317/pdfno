# Original fixtures

`study-sample.pdf` is the deterministic original two-page PDF generated by `scripts/generate-apple-project.py`, also copied unchanged to PDFnoUI resources. English sentences, layout and outline are PDFno-authored AGPL-3.0-or-later. The standard Helvetica font name is referenced, no font program is embedded. No private or third-party book is included.

The current PDFKit test checks text search, per-line PDF-space geometry, exact return validation, in-memory highlight projection, new-document/JSON round trip and edition replacement refusal. It is one simple Latin fixture, not a complete PDF fidelity/performance/accessibility matrix. Unicode/ruby/repeated-quote contracts are separate pure Swift original fixtures, not proof of EPUB parsing or Japanese PDF font extraction.

`study-sample.epub` and `security-sample.epub` are deterministic original PDFno fixtures generated by `scripts/generate-epub-fixture.py`. They include original English/Japanese text, author ruby, repeated quotes, emoji and combining marks, plus self-authored hostile markup for script/network refusal. No book, font, image or unknown third-party resource is copied. Actual Mac WebKit and UI tests cover only this limited reflow subset; comprehensive publication fidelity and mobile reading remain pending.

`DOCX/` contains 21 deterministic DOCX archives generated by `scripts/generate-docx-fixture.py`: the original semantic sample plus stored/descriptor variants and original hostile ZIP/XML/relationship/budget cases. Payloads are inert and use reserved `example.invalid`; unsafe documents are rejected by native tests before WebKit. No Word app, proprietary engine, copied document, external image or font is required. The UI's `study-sample.docx` is byte-identical to `DOCX/mammoth-sample.docx`. `mammoth-extraction.json` is generated by the actual fixed Mammoth chain and checked by Node/native tests; `hyperlink-sample.docx` has an ordinary external hyperlink whose label is preserved without opening its target.

`Comics/original-ustar.cbt.hex` is source-friendly hexadecimal for an independently generated real POSIX USTAR comic containing original PNG colors and XML. `scripts/generate-cbt-fixture.py` rebuilds it deterministically through Python tarfile, with decoded/source hashes and AGPL provenance in `Comics/SOURCE.json`. No book or external archiver is used.
