# Reproducible Kookit EPUB profile

This is build-time tooling, not an Electron/Node app runtime. PDF stays in PDFKit.

```sh
npm ci --prefix engine-build --ignore-scripts --no-audit --no-fund --registry=https://registry.npmjs.org
node --test engine-build/loader.test.mjs
node engine-build/build.mjs
```

Use Node 22+ and the committed lock. The build verifies original Kookit Git blobs, applies the checked script-disable transform, substitutes disabled PDF/Chinese modules and produces the EPUB-only engine plus full notices. Original `EpubRender.ts` is retained as the adaptation reference; the app uses `kookit-adapter.js` with a bounded loader and explicit async failures. `vendor/manifest.json` pins original source; `BUNDLE-INPUTS.json` identifies actual inputs. No upstream PDF engine, OpenCC mapping, extra product, fonts, test minified file or WASM is bundled.

The lock has 43 entries including the root and esbuild's optional platform packages. `DEPENDENCIES.json` records 16 actual JS/build packages and their original licenses/integrity. The installed platform esbuild package uses the upstream MIT license; it is a build tool, excluded from app resources/source distribution. JSZip selects MIT, pako retains MIT and its original zlib header, Rangy retains its actual npm 1.3.0 MIT file, and isarray's complete MIT text is preserved from its packaged README. Kookit core, CFI reference and embedded foliate licenses are preserved separately. See ADR 0003 and the dated source audit for upstream provenance limitations.

Generated app assets are committed for Xcode users; CI rebuilds and compares them. `node_modules` and compiler binaries are ignored. EPUB originals are local-only. Reproduction uses original fixtures generated by `scripts/generate-epub-fixture.py`; do not copy user books or unlicensed resources into tests.
