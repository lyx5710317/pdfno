## 背景与证据边界

PDFno 已有来源快照、类型化 PDF/EPUB 锚点、受限网络 provider、临时凭据、预算、取消及手动保存。若每个新阅读动作分别拼装请求，很容易出现范围、额度、输出版本和保存规则不一致。统一 Skills 的目的，是让这些规则可复用、可查看、可验证；不是把每项功能变成任意提示词聊天。

2026-10-05 实机确认参考应用为 `闪念 - AI 语音笔记`，bundle `com.chenxi.shanniankapian`，Mac 版本 1.0.32。观察到四种第二大脑模式、九项模板菜单、会话记忆说明，以及分别控制本地语义检索、MCP Server、MCP Client、Agent Tool Calling 的设置。九项菜单为系统总结、待办事项、会议纪要、思维导图、内容扩写、内容润色、智能翻译、日报生成、生活助手。

只查看控件与说明，未选择模板执行、发送 AI、上传文档、改设置、读取私人笔记或凭据。未取得模板全文、变量语法、模板编辑器、链式运行或结果保存证据；不能声称九项能力只是提示词。搜索和网页模式的存在也不等于已经测试真实检索。

[官方站点](https://ideasnap.xyz/)、[工作流](https://ideasnap.xyz/workflow/)及[集成说明](https://ideasnap.xyz/integrations/)支持同一产品身份及一般流程；[App Store](https://apps.apple.com/cn/app/%E9%97%AA%E5%BF%B5-ai%E8%AF%AD%E9%9F%B3%E7%AC%94%E8%AE%B0/id1397149726) 的移动版本更新说明提及 Skills/上下文，不作为 Mac 已实现或实测证据。以下契约均为 PDFno 原创设计，不复制私有实现、模板文本、图标或素材。

## 决策：Skill 是受限任务契约

一个 Skill 由以下部分组成，不能单凭提示词获得输入或工具权限：

| 契约 | 内容与责任 |
| --- | --- |
| 身份与版本 | 稳定 `skillID`，不可变 `skillVersion`，独立 `manifestSchemaVersion`、`promptVersion`、`resultSchemaVersion`、`validationVersion`；修改发布为新版本，旧记录保留旧身份 |
| 输入 | 格式、语言、范围和长度，来源快照/锚点版本；适配器是否真的能提取该范围 |
| 参数 | 类型、枚举、默认值、上下限；每次运行固化参数，未知字段拒绝；目标语言明确选择 |
| 模型能力 | 所需协议、完整 JSON、输出上限、是否需要工具/向量/多模态；声明与实际验证分开 |
| 模板 | 固定系统规则、受类型约束的参数及正文数据槽；正文/外部网页/检索结果均是不可信资料 |
| 输出与校验 | 固定 schema、来源引用、跨度与语言质量分离；失败不能伪造成功结果 |
| 权限与预算 | 显式数据范围、接收方、允许工具、请求/字节/token 限额、取消和重试策略 |
| 结果生命周期 | 任务归属、缓存身份、人工保存、版本兼容、编辑保护、导入导出与回滚 |

## 注册与兼容性

P0 用编译内置 registry，用户无需编辑文件即可继续点击翻译、解释、日语按钮。Registry 明确显示已提供、候选、不可用及原因，禁止因某个 manifest 被导入而把不存在的 reader/provider/tool 注册为可用。

每项声明最低 runtime/manifest 版本和输入/输出契约。运行前验证 ID、唯一版本、允许字段、语言标签、参数枚举、大小上限、版本支持及引用的 validator。未知 schema、未来版本、缺 validator、重复冲突 ID 都禁用并保留原件；不静默丢字段或降级。内置 ID 空间与个人导入空间隔离，不能覆盖内置安全规则。

模板版本记录内容摘要、来源、作者自报信息和审核状态。内容摘要证明一致性，不证明可信度。新版本不会自动替换旧记录或在途任务。禁止自动下载更新或在模板包中携带脚本、二进制、密钥、动态插件与依赖安装指令。

## 输入与上下文

`selection`、`pdfPhysicalPage`、`epubCurrentSpine`、`explicitResourceRange`、`singleBookRetrieval` 是不同权限；没有隐式 `wholeLibrary`。EPUB 一个 spine 不自动等于目录逻辑章节。扩展范围必须重建计划及用户确认，不能从按钮标签推断。

P0/P1 先支持实际 PDFKit/EPUB adapter 的有限文本输入。PDF 完整物理页和 EPUB 当前 spine沿用已实施的 ≤3000 UTF-16/≤6 段，每段 ≤500 UTF-16；不因新 runtime 提高上限。选文保持 ≤500 UTF-16。其他格式、扫描页/漫画 OCR、图片或附件不自动进入输入；没有文本时提供明确原因。

快照至少固化 book/edition、源文件摘要、extractionVersion、reader session/documentVersion、真实格式 locator、quote/span、单位和正文摘要。不得把旧 UTF-16 offset 重新解释为 code point。模型 span 使用规定的 Unicode scalar/code-point 协议，并由宿主转换、验证完整 grapheme 边界及逐 scalar 引文；来源坐标只能由真实 adapter 给出。

默认上下文只有当前显式来源。用户笔记、先前回答、阅读历史、其他书、网页和个人记忆不自动注入。会话上下文须选择参与的资料卡、显示摘要和字数、冻结版本；删除卡后下一次请求不得仍带旧资料。已保存笔记搜索与书籍全文索引是不同来源，不混称 RAG。

支持的模板变量是封闭集合，例如 `sourceText`、`targetLanguage`、`readingLevel`、`question`、宿主生成的 `sourceRefs`。变量类型/字节上限/必填和转义方式由编译器固定。禁止变量求值、文件路径展开、环境变量、shell、任意 URL 自动抓取和模板自定义 system 权限。源文中的“忽略指令”等仍是引用数据。

## Provider、权限和运行状态

保留已有两类选文配置：官方 DeepSeek 有限协议；自定义 HTTPS OpenAI-compatible 的有限 chat/completions JSON 协议。后者要求 Bearer、system/user、`stream:false`、`max_tokens`、`response_format:json_object`、单 assistant 完整 stop。兼容标签不证明任意模型支持 schema/SSE/vision/embedding/tool calling。当前拒绝全部重定向的规则不变。

Provider capability 用可核验 profile 描述；本地静态规则可验证，真实服务兼容/质量测试另获准执行。缺能力时禁用并说明，不静默换服务、模型、mock 或不受限纯文本。凭据由宿主会话解析，永不进入 manifest、WebView、模型输出、缓存、日志或导出。持久 Keychain 和本地 HTTP/局域网模型仍走独立决策门禁。

运行计划先显示 Skill/版本、范围/来源、参与上下文、最终接收方 host/path、模型、请求/字节/token 上限、价格/usage 可信度、工具权限和保存位置。改变任一有权决定发送内容或接收方的项，使旧确认失效。打开面板、搜索模板、编辑参数、预览或导入不会发请求。是否沿用有效确认由显式策略决定，不能用“用户点过一次”授权后续更大范围。

P0/P1 工具权限为空，模型只返回数据；生成结果与保存结果分开。P3 外部工具默认关闭，按已批准的服务和工具白名单单独确认，逐调用显示接收方/参数/数据预览。书中文字、模型计划和导入模板均不能授权工具。与原生文件/账户/书库相关的 tool 不直接暴露模型读写能力。

`planned → awaitingConsent → queued → requesting → validating → completed`，分支 `failed/partial/cancelled/staleSource`。非流式 profile 不显示伪 streaming。宿主维护 taskID、source digest、配置 generation、Skill 版本与取消 token，迟到响应只可回原任务且不能覆盖新来源/草稿。切书/关窗采用原入口取消策略；结果完整保留与否必须可解释。取消后不再启动排队段，已发送的请求可能计费。

初期保持已有会话预算：翻译/解释/日语与后续获准英语或新选文 Skill 共用 `AppAISession.selection` 的三次网络尝试，不能每导入一个 Skill 新领三次；PDF 页和 EPUB spine各按已有独立六次预算。独立无书短句测试仍为自己的三次/128 output tokens。失败、超时、取消保守计数，缓存命中不增加尝试。原有1024 output tokens/30秒/64KiB限制不变；新 profile 若需要更大额度，先独立审批实现和验收，不能自行抬高。

P0/P1 并发沿用既有受限串行计划，**自动重试为零**。主规格8.3的并发2/自动重试2只是未来一般建议，不生效于本 ADR。之后重试需要明确 failed 段、剩余额度和重复计费风险；未知是否已提交时不自动重发，provider 幂等仅按已验证能力采用。额度不是货币硬上限；价格或 usage 未知如实显示未知，不推算“免费”。

错误至少区分配置、缺能力/权限、空文本/输入过长、认证、余额、限流、超时、取消、网络结果未知、截断、schema、来源/跨度错误、来源过期、预算耗尽与保存冲突。失败保留安全诊断及原快照，不记录原服务响应、凭据或书籍全文；不会为修 JSON 静默再次联网。

## 结构化结果、来源验证、缓存和保存

通用结果 envelope 带 request/task、Skill/各版本、provider/config generation、来源身份、输入/参数摘要、校验状态、预算/usage 可信度和 payload；每类 payload 由自己的 validator 管理，不能用一个任意字典跳过类型验证。

本地分配 `sourceRefID` 指向已选快照或检索 chunk。模型只能引用此集合；不能自造页码、书籍、坐标、CFI、工具成功或“已验证”。每个 citation 回查当前 edition/extraction、locator、quote/hash；重复短语有明确 occurrence/span，无唯一匹配则拒绝回跳并标歧义。变化后标 stale，保留旧结果但不谎称仍可定位。

解释分开“原文引文、释义、推断”；论证结构分开作者明示和模型推断；学习卡的问题、答案、每项依据均受限于原资料，推断标注不能代替依据。允许“材料不足”，检索到相关片段不证明结论被支持。结构/引用通过与翻译、语法、论证正确性分开验收。

缓存键覆盖 source/edition/extraction/定位及正文摘要、范围/上下文快照摘要、Skill/prompt/result/validator/runtime版本、全部参数、provider/model及配置 generation。命中须再次检查来源和版本；不同目标语言/上下文/provider/校验规则不得共享。排除 key/requestID；相同配置但凭据已撤销时仍不能自动发送。持久化缓存另获准，优先沿用已有仅内存、已验证结果缓存；失败、半成品和旧 validator 结果不冒充成功缓存。缓存命中与真实网络调用独立记录，不虚构 usage。

保存必须由用户操作，引用/AI payload 与用户正文分开，requestID 幂等，revision/CAS 防覆盖用户编辑。AI 再生成产生独立结果版本，不覆盖已改笔记；保存冲突让用户比较/另存。局部翻译可读，但保存说明成功/缺失段，不能标整页完成。

初期用适配器保留 `learning-v1`、`japanese-learning-v1`、既有 page/spine 文件及 prompt白名单，不能将旧记录一律重写为 Skills envelope；未来英语文件需等待实际候选合并。新增结果仓库单独 schema/备份/原子写入，未知/未来/损坏文件只读保护，旧原件保留。迁移需样例演练、dry-run、用户确认、幂等和回滚；本次不迁移真实数据。

## 编辑、导入、导出与分享

P0 内置只读；P1 原创任务先固定 prompt/schema；P2 再提供个人模板编辑器与导入导出。编辑器显示输入范围、受限变量、结果类型、模型能力和工具权限，不藏在长提示词内。修改内置模板生成个人 fork，继承可见的来源版本；权限/validator不能由模板任意放宽。

先做离线 lint、原创假资料预览及 mock 验证，保存模板不会生成。错误指明字段/行号且不执行任何内容；包大小/层级/字段/路径严格限制。导入未知 schema/能力/工具只保留并禁用，不能触发联网安装或加载文件。导出只包含模板、契约、版本及非秘密出处/许可，不含书、笔记、结果、历史、key、服务私有配置。分享以用户选定的脱敏包为单位；许可和作者声明独立验证，不因 PDFno AGPL 开源而认可所有第三方模板。

初期不自动串联。后续有限 workflow 显示步骤 DAG、各自输入、输出 schema、接收方、预算与暂停点；步骤输出是数据，不能提权或自动扩充范围；失败/取消停止后续，已成功结果可读，不重复发送。工作流整体获准也不能绕过逐工具敏感数据预览。通用 agent、自主研究循环和脚本市场不是本 ADR 的首期目标。

## 单书检索与外部能力边界

P2 在本机对一书已支持的可提取文本建立版本化 chunk/index，首片可先词法检索，向量 embedding 是否本地及其模型/许可/安装另决策。检索不会默认发到外部 embedding服务。本地索引存放与权限不等于外发授权；回答只外发本次选择的命中片段和问题。

索引 manifest绑定 sourceHash/extraction/chunker/index/embedding版本、资源覆盖、失败/跳过块和重建状态。source/extraction/version变化触发增量失效；重建先暂存校验后原子切换，取消保留旧索引及其旧版本标识；不混合新旧 edition。无索引、部分索引、陈旧索引、空/弱命中均显式显示。扫描 PDF/图像漫画无 OCR 时明确未覆盖，不编造全文或完整率。

跨章节 QA 只能从用户批准的一书资源范围检索，有确定性排序/数量/输入预算、可预览片段和逐句引用回查。不能因书名相同匹配其他版/其他书；无证据时回答材料不足。页/spine/local saved-note搜索不是这套全文检索已实现的证据。

P3 外部研究由显式问题或选定短引文起步，网页来源卡含 URL、获取时间、服务运营者和摘要；不得默认传整书/私人笔记。外部证据与书内引用分开，引用 URL 不代表网页被真实读取。首次网络/服务权限、网页内容不可信、防注入/重定向/路径及响应上限仍由宿主验证。

**MCP Client** 是 PDFno访问外部服务；**MCP Server** 是其他应用访问 PDFno，方向和授权不可互换。先考虑远程 HTTPS、只读、固定服务和工具白名单；不默认提供 stdio、shell/Node启动或任意代码。Server 更后期：默认关闭、显式启动/停止、绑定地址和认证决策、仅用户选定的只读资料、撤销与调用记录；不暴露任意文件/书库/编辑/导出/账户权限。开放端口或本地地址也需要评估访问方，不假设 localhost 就安全。

目录只保存服务描述及配置候选，导入不连接。标识目录维护者、server运营者、上游来源、官方/社区、核验 URL/日期、工具 allowlist、认证/费用/限流、许可/条款及状态；定期失效而非永久“可信”。模板、模型、检索索引、MCP服务和目录是五种对象，不共用一个“插件”权限开关。

## 取舍与后续门禁

采用内置 registry→原创受限 Skills→单书检索/个人模板→外部研究/MCP 的顺序。保留 Mac Swift/PDFKit＋Kookit/WKWebView、AGPL、后续 iPhone/iPad；纯领域规则可共享，reader能力与 UI逐端验证。Bookno/iCloud实际同步仍推后，当前 ADR 不增加云容器、账户或同步依赖。

代价是先写 typed契约和适配器而非立刻开放任意模板；收益是旧入口不受影响、每次外发可解释、版本和引用可重放。MCP、索引和模型质量均有独立运行/许可风险，需要按路线逐片验收。独立累计安全/依赖审计仍 **UNVERIFIED**，新增文档和一般检查不能替代它。

不适合照搬会议纪要/录音、待办执行、生活助手、跨应用个人记忆、私人知识库一键暴露或通用联网 agent。阅读场景优先原文解释、论证结构、学习卡、有限翻译/语法与可引用单书问答；原生快捷入口可进入预览，但不通过快捷键绕过发送确认。

下一次实现须明确获准哪张 RS任务卡、更新真实基线，完成该片 mock/来源/保存/取消验证，另说明真实语言质量、服务调用、设备适配哪些未执行。此文档的任务次序和示例不是实现承诺或请求权限。
