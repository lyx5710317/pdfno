# ADR 0003 — Native shell, PDFKit and Kookit EPUB

Date: 2026-10-03. Status: accepted direction; first Mac reflow slice validated; full platform/resource coverage pending.

The user confirmed continuing AGPL development with Swift/PDFKit retained and Kookit preferred for other formats. This supersedes the earlier unselected-engine status. The application stays native SwiftUI/AppKit/UIKit. PDF is routed solely to PDFKit; a limited Kookit core adapter runs EPUB content inside a Mac WKWebView. It does not supply application UI or a Node/Electron runtime. Mac is delivered first; shared models and mobile targets remain, with mobile EPUB UI deferred until separately validated.

Core is pinned to `95f602ed62d204af0de9278cf53212c309b34bfc`, package 1.0.4. `engine-build/vendor/manifest.json` retains 23 original Git-blob-verified source files. The EPUB-only adapter replaces EpubRender's unrestricted fallback ZIP loaders and error-prone Promise wrapper. A checked build transform always disables book scripts. It substitutes disabled PDF-search and Chinese-conversion modules; actual bundle inputs exclude the PDF engine, OpenCC mapping, MOBI/comic/DOCX engines, extra products and unknown test/minified assets.

`engine-build/package-lock.json` pins actual official npm dependencies and integrity; Node/esbuild are build tools. `DEPENDENCIES.json`, original license texts, `BUNDLE-INPUTS.json`, corresponding source and generated `Resources/EPUB/Notices.txt` accompany the derived engine. Kookit is AGPL-3.0-or-later; CFI source declares AGPL-3.0; foliate source and npm components retain their own notices. There is no claim that all third-party code is PDFno-owned or relicensed. The optional OpenCC mapping is excluded; reintroduction requires a separate data/NOTICE audit.

Native imports check raw ZIP central/local paths, duplicates, symlinks, encryption and declared budgets. The JS loader checks the exact native path whitelist and caps actual streamed decompression: 20 MiB archive, 1000 entries, 4 MiB entry, 50 MiB aggregate. Static PNG/JPEG resources have 4M pixels per image and 16M aggregate limits; external fonts, SVG, animation and other resource types are outside this slice. HTML/XML rejects entities/DTD, strips active content, and restricts resource references. CSP, nonpersistent WebKit storage, per-protocol content rules, native resource/navigation allowlists and script-disabled book frames remain in force. Selection is read from the trusted parent because WebKit may suppress listeners inside a script-disabled frame.

Each request is scoped to a random session, book/edition/hash, document version and request UUID. Commands are serial; cancellation invalidates generation and pending continuations; old results cannot update a new session. Errors/timeouts close the failing session. Persistent anchors use canonical UTF-16 source offsets excluding rt/rp, exact quote/context and resource/spine identity; ruby remains displayed. Reflow and return validate the original source, without fuzzy matching. CSS highlights or empty fixed overlays project notes without rewriting original bytes.

`epub-v1.json` and `<sha256>.epub` are independent of the existing PDF manifest. Notes/progress are validated and manifests atomically written with previous-version backup; corrupted/future stores stop writes. There is no real-user migration or cloud configuration. Revert this commit to return to the PDF-only runtime; keep the EPUB manifest/originals for a later compatible version. Do not delete existing user assets or restore backups blindly.

Remaining limits: first scope is non-DRM reflow EPUB with original fixtures; fixed layout, comprehensive image/font fidelity, arbitrary large publications, complete accessibility/keyboard coverage, search, note editing/deletion, crash injection and mobile reading are pending. Other Kookit formats need their own dependencies, fixtures, resource limits and acceptance before exposure. Comics, conversions and AI are not delivered by this choice. Evidence is recorded in `VALIDATION.md`; static auditing alone does not satisfy runtime acceptance.
