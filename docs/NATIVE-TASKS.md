# Native implementation status

Date: 2026-10-03. Swift native UI + PDFKit, independent Kookit EPUB adapter, Mac/iPhone/iPad and AGPL remain confirmed. Latest approved delivery order: complete the Mac version first, then adapt its content/interaction to iPhone and iPad. Keep both targets and shared identities/models; mobile UI completeness is not this phase’s delivery gate. Current capability includes local PDF, Mac reflow EPUB/CBZ and limited Mammoth DOCX reading, local DOCX body-text export and bounded PDF current-page bilingual text, a bounded user-operated DeepSeek PDF/EPUB selection translator/explainer, explicit local mock and a separate fixed-sentence probe. The user reported three successful independent probe calls; reading quality and bill remain unverified; the full [v0.3 specification](PDFno_AI_Development_Spec_v0.3_Native.md) remains the requirements inventory.

Provisional adjustable developer baseline: macOS 14 / iOS/iPadOS 17, Swift 6, Xcode 16.4+. This supports current SwiftUI APIs and leaves CKSyncEngine compatibility; it does not enable cloud behavior. Two development bundle IDs are local placeholders, no registered identity is claimed.

Retired CLI N00/N01 were capability helpers, never native reading evidence. Their prior behavior is recoverable at baseline `2c40a8f`; current runtime has no dependency on them or Electron. See [migration/recovery](NATIVE-MIGRATION.md) and [validation](VALIDATION.md).

Mobile builds are retained as compile evidence. Dedicated mobile UI refinements and acceptance now follow the Mac milestone; any earlier failures remain honestly documented, not treated as a reason to delay Mac delivery.

Next AI gate: the user may manually enter a temporary key in the existing settings and confirm a <=500 UTF-16 PDF/EPUB selection before personally sending translate/explain. The agent never reads/fills a real key or clicks submission. Actual reader language quality/bill and signed persistent Keychain remain separate acceptance gates. Further EPUB coverage, cover/thumbnails/accessibility and each external integration need scoped acceptance. The bounded Mac PDF current-page slice is integrated; chapter/whole-book translation remains a later slice; the complete future product is not implied by this working slice.

After the four current slices complete, freeze the delivered commit and stop new features for the user-requested independent accumulated code/dependency/license audit and unified acceptance. The handoff runbook and original fixture/hash inventory are provided separately; integration tests are not a completed whole-project audit.
